# Bloom — сайт салона красоты

Учебный проект: онлайн-запись в салон красоты. Чистые HTML и CSS без JavaScript,
минимальный PHP для входа и сохранения записей.

## Возможности

- каталог услуг с поиском и фильтром по категориям (фильтр на чистом CSS);
- мастера и расписание свободных слотов;
- регистрация, вход и выход (сессии PHP);
- онлайн-запись: выбор услуги, мастера, даты и времени, проверка занятого слота;
- профиль клиента со списком его записей;
- админ-панель: список пользователей и записей, смена статуса записи.

## Запуск

Нужен PHP 8.1+ (подойдёт PHP из XAMPP). Из папки проекта:

```
php -S localhost:8000
```

Затем открыть http://localhost:8000/index.php. Либо положить папку в `htdocs` XAMPP
и открыть `http://localhost/Bloom/`.

> GitHub Pages PHP не выполняет, поэтому на нём сайт работать не будет — только локально
> или на хостинге с PHP.

## Структура

| Файл | Назначение |
|---|---|
| `index.php` | главная |
| `services.php`, `details.php` | каталог услуг и карточка услуги |
| `masters.php` | мастера и расписание |
| `booking.php`, `confirm.php` | запись и подтверждение (нужен вход) |
| `profile.php` | профиль и записи клиента (нужен вход) |
| `admin.php` | админ-панель (только администратор) |
| `login.php`, `register.php`, `logout.php` | вход, регистрация, выход |
| `about.php` | о салоне и контакты |
| `data.php` | хранилище, сессии, вход, CSRF |
| `nav.php` | меню (зависит от того, вошёл ли пользователь) |
| `css/style.css` | стили |
| `images/` | изображения |
| `data/` | JSON-файлы с пользователями и записями, создаются при первом запуске |

## Хранение данных

Базы данных нет: пользователи и записи лежат в `data/users.json` и `data/bookings.json`.
Папка `data/` в репозиторий не попадает (`.gitignore`); чтобы сбросить данные к
начальным, достаточно удалить её.

## Ограничения

- форма «Редактировать профиль» пока ничего не сохраняет;
- блок «Услуги» в админ-панели статичный (добавление и удаление не работают);
- список услуг и мастеров в форме записи задан в `data.php`.
